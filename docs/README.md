# Interactive Electroneutral Ion Transport

Static iPad-friendly website built from the existing validated SciPy ENNP BVP profile tables.

## Publish on GitHub Pages (no command line required)

1. Create a **public** repository called `ion-transport-interactive` at https://github.com/new.
2. Extract `GitHub_Pages_Ion_Transport_Starter.zip`, and open the enclosed `ion-transport-interactive` folder.
3. In the new GitHub repository, select **Add file → Upload files** and upload the **individual files inside that folder**, not the ZIP itself. Place them directly in the root of the repository. The essential published files are `index.html`, `styles.css`, `app.js`, `manifest.json`, `dimensional.bin.gz`, `da.bin.gz`. You can also upload this `README.md`, `.nojekyll`, and `export_data.py`.
4. Select **Commit changes** to upload the files.
5. In the repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**; select branch **main** and folder **/(root)**, then **Save**.
6. Once published, open `https://YOUR-USERNAME.github.io/ion-transport-interactive/` on the iPad. Use the Share menu and **Add to Home Screen** if desired.

The website does not need Python, SciPy, JAX, npm, or a server-side application at runtime. The static files are hosted by GitHub Pages, and all interactive computations occur inside the browser after the precomputed data downloads.

### Testing locally

From inside this folder, run:

    python -m http.server 8000

Visit http://localhost:8000/ in your computer's browser. Do **not** double-click `index.html` because browsers typically restrict loading local data with `file://` URLs.

## Views and model

**Dimensional:** five controls for `c0` (0.05–2 mol/m³), `cs` (0.05–2 mol/m³), `L` (1 nm–1 m), `k` (0 or 1e-12–1e10 m³/(mol·s)), and `D_star` (1e-9–1e-1 m²/s). The two concentration parameters use linear scales; the remaining ones are logarithmic, with a special zero-reaction setting. The four relative ionic diffusivities stay fixed, so the effective dimensional diffusivities scale with `D_star`.

**Nondimensional:** one logarithmic `Da` control (1e-6–1e10); the other nondimensional parameters remain fixed.

Both views show four ionic concentrations in the top plot and reaction rate beneath, with a shared position axis. The original H⁺ red, Na⁺ orange, OH⁻ blue, Cl⁻ green, and reaction magenta colors are retained.

The dimensional solver data depend on two dimensionless groups:

    Da    = k*c0*L**2/D_star
    gamma = cs/c0

The dimensional table includes 3,926 solved BVP snapshots. Between the tabulated `(Da, gamma)` values, the browser follows the original `ENProfileLookup.concentrations` algorithm, interpolating after aligning the reaction fronts. **These are numerical illustrations, not fresh exact BVP solves at off-grid settings.** The Da-only table includes 321 individually solved profiles. The dimensionless slider retrieves the corresponding table profile at every 0.05-decade step.

The reaction law used in the browser is `R = k*c_H*c_OH`, where the rate constant has units m³/(mol·s).

### Data provenance

The compressed browser tables were converted directly from the existing files `EN_Five_Slider_Smooth_Kit/sliders/en_dimensional_profiles_2d.npz` and `en_da_profiles.npz`, generated by the original SciPy BVP solver. The website preserves 64-bit positions along the adaptive meshes to resolve narrow reaction layers. The conversion script `export_data.py` is optional; it can regenerate the browser files if you later change your source model and recompute the `.npz` tables. Its `SOURCE` path points to the original kit placed alongside the website folder, so adjust that path if you reorganize your files.

### Important limitations

- GitHub Pages publishes a **public website**; avoid uploading confidential research, account information, or unpublished data you do not intend to share.
- The compressed dimensional dataset is about 19.5 MB, within GitHub's 25 MiB browser-upload limit per file. The first page load requires a suitable network connection. Once data has loaded, moving the sliders does not require further computation from a remote server.
- **This first version is not guaranteed to work offline.** Test internet reliability at the presentation site or keep the desktop Python slider as a backup.
- Extreme parameter combinations, particularly nanometer lengths or extremely high Da, can fall outside the domain where the continuum electroneutral approximation is physically defensible. Use the original SciPy solver for quantitative predictions.
